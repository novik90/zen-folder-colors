# zen-folder-colors

Мод для Sine (менеджер модов Zen Browser): добавляет в контекстное меню папок
вкладок выбор одного из 16 цветов. Цвет перекрашивает иконку папки, фон её
строки-заголовка и фон вложенных табов.

## Команды

Сборки и зависимостей нет — чистые JS/CSS. Проверка — установкой в профиль
Zen через Sine и ручным прогоном (см. README).

## Архитектура

- `theme.json` — манифест мода для Sine (точка входа: список скриптов и CSS).
- `folder-colors.uc.js` — JS, работающий в chrome-контексте окна браузера:
  инжектит подменю выбора цвета в попап `#zenFolderActions` и ставит
  `folder.color = "zfc-<имя>"`.
- `userChrome.css` — палитра (16 переменных `--zfc-*` на `:root`) и стили
  `zen-folder[color="zfc-*"]`: CSS-переменные иконки Zen
  (`--zen-folder-*-bgcolor`, `--zen-folder-stroke`) и тинты фона.
- `preferences.json` — настройки мода в UI Sine.

Ключевое решение о персистентности: выбранный цвет хранится в штатном
свойстве группы табов `color`, которое SessionStore сохраняет между сессиями
(так же Zen хранит `zen-workspace-color`). Своего хранилища у мода нет.

## Конвенции

- Значения цветов — только с префиксом `zfc-`: нативная палитра Firefox
  (blue, purple, …) занята, а `zen-workspace-color` означает «цвет рабочего
  пространства» и используется как значение по умолчанию.
- Палитра правится только переменными `--zfc-*` в начале `userChrome.css`,
  не размазывать hex по селекторам — пользователи мода настраивают цвета
  именно там.
- `.uc.js` обязан переживать пересборку Sine без дублей: скрипт запускается
  заново, поэтому в начале — destroy предыдущего экземпляра (образец —
  Vertex-Mods/Advanced-Tab-Groups).
- Совместимость проверяется с актуальным Zen (ветка desktop dev): разметка
  `zen-folder` и попап `#zenFolderActions` — внутренности браузера и могут
  меняться между версиями.

## Чего не делать

- Не трогать нативные значения `color` Firefox-групп и `zen-workspace-color` —
  на них завязаны стили самого Zen.
- Не хранить состояние в pref/localStorage — это второй источник правды,
  который разойдётся с SessionStore.
